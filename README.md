# 隐园电脑网页版 V0.2 · 悬停时刻

这是一个无需安装依赖的可运行灵魂原型，打通：

**入园 → 在树下、水边或小径停留 → 可选放下一颗石头 → 我的园 → 体验反馈**

## 如何打开

最简单的方式：双击 `index.html`。

为了获得更稳定的浏览器体验，也可以在本文件夹启动本地网页服务后访问：

```powershell
python -m http.server 4173
```

然后打开 `http://localhost:4173`。

## 造园师验证面板

打开 `http://localhost:4173/?research=1`，右下角会出现“验证记录”。面板可以查看：

- 完成悬停次数；
- 平均悬停秒数；
- 留在园中的记录数量；
- 反馈中“有/有一点感到可停下”的数量；
- 导出当前浏览器中的测试事件、反馈与痕迹。

本版本不自动上传任何内容。每位测试者最好使用独立浏览器配置或测试后导出并清空本机数据。

## 飞书连接

`config.js` 中保存两个公开入口：

- `guideUrl`：悬停时刻的飞书使用说明；
- `deepRecordUrl`：飞书完整记录仪式。

私人记录不会进入飞书。首轮测试完成后，将导出的 JSON 脱敏整理，再人工录入飞书验证仓库。

## 当前数据边界

- 园中记录、反馈、事件：浏览器 `localStorage`；
- 删除：用户可在“我的园”逐条删除；
- 清空：造园师面板可清空本机全部测试数据；
- 云端与账号：V0.1不包含。

产品目标、判断线与测试脚本见 `PRODUCT_V0.1.md`；现有飞书与本地资产如何进入或暂缓于本版本，见 `ASSET_MAP_V0.1.md`。

## 悬停时刻的当前版本

- 树下、小径与水边属于同一座连续的园，移动时只改变观看位置；
- 白日与夜晚保留相同地形和物件，光线、雾、水面与虫鸣随时间变化；
- 园声使用原创 `bamboo-courtyard-east-lake-v11.wav`，鸟会随园声偶尔转头、摆尾；
- 云、薄雾、水光、树冠与萤火会自行变化，用户什么都不做，园子也会继续生活；
- 在水边触碰、在其他位置长按，会产生一次短暂涟漪，没有奖励或结果；
- 悬停过程中不显示计时，离开时也不要求回答情绪问卷；
- 用户可以放下一颗小石头，也可以什么都不留下；石头会在再次进入与“我的园”中保留；
- “随时离开”始终保留，“先停到这里”在进入约 12 秒后出现。

## 留个口信（2026-10-23）

从「如何入园」→「留个口信」打开。手机竖屏提示页也能打开「如何入园」。关闭返回说明，再关闭说明即可回到原来的园中位置。「回到园里」直接返回原来的页面。输入框固定高度，长文字在框内滚动。草稿独立存于当前标签页的 sessionStorage，误关面板、刷新均可恢复，成功后清除；不承诺关闭标签页或浏览器后的恢复。浏览器禁止存储时仍保留本页内存草稿。

口信通过同源接口实际写入 D1 数据库，写入成功才显示收到。Cloudflare 正式环境使用私有数据库 `yinyuan-messages` 的 `messages` 表；本机验收使用独立的本地数据库，不写远程库。旧验证面板里的浏览器反馈不属于这条接收链路。

本机验收（需要项目依赖已安装）：

1. `pnpm build` 生成静态页面。
2. `pnpm db:local` 初始化本机数据库。
3. `pnpm dev:feedback` 打开 `http://127.0.0.1:4187/`，页面与接口共用此地址。
4. 另开终端运行 `pnpm inbox:local`，访问 `http://127.0.0.1:4188/` 查看本机测试口信。此工具仅监听本机，不进入发布包。

原有 `python -m http.server` 仅可预览页面，不能接收口信。双击 index.html 也不会发送，均不会显示虚假成功。

接收接口 `POST /api/messages` 只接受正文及每条口信的随机防重复编号；表中只有编号、正文、服务端 UTC 提交时间。禁止 GET 读取、跨来源提交和额外字段；单条上限 6000 字符，请求体上限 26KB，每分钟全站最多接受 30 条，不持久化 IP、设备编号或联系方式。这个轻量总量限制不等同于完整反滥用系统。网络不确定时重试沿用同一编号，保存同一口信不会重复入库；修改正文后使用新编号。只有数据库确认存在这条正文，客户端才显示收到。15 秒无响应保留草稿并允许重试。不会读取或附带「我的园」记录，不写正文到应用日志；Cloudflare 平台本身的请求日志应在上线前核对保留设置。

发布流程：本地发送及收件箱验收后，将改动推送到 main，触发已有 Cloudflare Pages 自动部署。`wrangler.jsonc` 中 FEEDBACK_DB 对应已创建的私有库，发布时确认采用此配置及原有 `node build-static.mjs` / `dist` 构建设置。发布后发送明确标记的测试口信，核对云端表中确实保存。配置中的数据库 ID 是资源标识，不是密钥；前端没有数据库访问凭据。不增加公开读取接口和网页回信功能。

上线后查看：Cloudflare 后台 → 存储和数据库 → D1 SQLite 数据库 → yinyuan-messages → 探索数据 → messages。查看需要登录你的 Cloudflare 账号。已保存的正文不应复制进 Git、公开页面或普通日志。通知功能暂不接入。

官方参考：https://developers.cloudflare.com/pages/functions/bindings/ 、https://developers.cloudflare.com/pages/functions/local-development/ 。

## 水边与原地书写修复（2026-10-23）

- 日间使用 `yinyuan-water-day-loop-v2.mp4`，夜间使用 `yinyuan-water-night-loop-v3.mp4`，均为 1280×720、25fps、无声视频。首尾顺向叠化、稳定岸边，合成约 20 秒的连续流以减少浏览器循环寻帧。视频首帧和底图匹配，只在解码就绪后显示视频，循环时不撤下可见画面。
- 夜景通过 built-in imagegen 对日间首帧调整光线，提示词与素材路径见 `scripts/water-night-relight-prompt.txt`；夜间运动来自日间水流，不沿用草木不一致的旧夜间视频。`prepare-water-video-loop.py` 生成日间循环，`match-night-water-video.py` 生成对应夜景，需要 FFmpeg、numpy、Pillow。
- 水声保留原素材，仅将默认增益从 0.92 调整至 0.32（约降低 9dB），继续手动开启，不随视频自动出声。不同耳机、外放设备的实际音量仍需分别体验。
- 手机关闭环境自动飘种和长按散种，水边所有设备均不散种；不影响主动书写时选择植物。
- 「留一句在这里」恢复原地小卡片，不跳整页；保存为当前「我的园」支持的文字记录，取消或关闭保留未保存文字。移除该卡片及入园说明中的石头选项和旧文案，不删除历史记录。
